# PATShield

Industrial Waste Heat Recovery (WHR) Feasibility Engine — helps Indian manufacturing plants assess WHR investment feasibility and BEE PAT scheme compliance.

## What it does
- Simulates plant load and waste heat data
- Calculates NPV, MIRR, and payback period for WHR investments
- Sizing recommendations for recovery technology
- Cost-of-inaction analysis for non-compliance risk

## Tech Stack
- **Backend:** Python (FastAPI/Flask)
- **Frontend:** React + Vite + Tailwind CSS
- **Database:** SQLite
